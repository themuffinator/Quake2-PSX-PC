Installation & play

User guide

A native PC recreation of Quake II for the PlayStation. Bring your disc, choose your controls, and start playing.

For Windows, Linux and macOS. This guide works offline.

01 / Getting startedFirst launch

You need your own Quake II PlayStation disc or disc image. The PC and Nintendo 64 editions do not work. No game data is included in this download.

  1. Extract the whole release archive.

    Use the archive for your system: Windows x64, Linux x64, or macOS Apple silicon. Keep the executable and its runtime libraries together. Run from the extracted folder, not from inside the archive.

  2. Open Q2PSX-PC.

    On Windows, double-click q2psx.exe. On Linux or macOS, open a terminal in the extracted folder and run ./q2psx. The disc selector opens in a window.

  3. Choose your disc.

    Select a listed disc, or choose BROWSE IMAGE and open your .cue file. You can also drop an image onto the selector. Select START GAME.

    Keep the CUE and every BIN track it names together, with their original filenames. If the disc is missing from the list, use Browse; you do not need to copy it into the game folder.

  4. Start the campaign.

    After the logos and intro, choose START → SINGLE PLAYER → NEW GAME, then a difficulty. The opening film leads into the first level. A key press or click skips the current logo or film.

The selector remembers your last disc. To change it next time, run the executable without a --disc argument.

Supported discs and image formats

The identified releases are Europe SLES-01534 and USA SLUS-00757. Other revisions are not established as supported.

Choose the CUE when your image includes one.
SourceWhat to use
CUE + BINRecommended. Raw Mode 2 / 2352-byte images retain the data needed for music and films. Multi-file and multi-track CUEs are supported.
BIN or IMGRaw images are supported. A matching CUE is used when found; open the CUE directly when available.
ISOSupported for data. A 2048-byte-sector image cannot retain the raw XA sectors needed for music and films.
Physical CDWindows and Linux have drive support. Music and films require raw-sector access; compatibility depends on the drive and permissions.
Other formatsCHD, MDS/MDF and PBP are unsupported. CCD descriptors and SUB sidecars are not parsed; choose the associated raw IMG instead.

Windows also includes optional Play.vbs and Play.cmd launchers. Play.vbs opens the selector. Play.cmd uses disc/game.cue when present, or opens the selector otherwise.

Menus

Use the arrows to navigate, Enter or Space to select, and Esc or Backspace to go back. The mouse can select rows and drag sliders; right-click goes back. At a mission tally, press Fire to continue.

Gamepads

A connected gamepad is assigned automatically in single-player. In menus, the D-pad or left stick navigates, the bottom face button selects, the right face button goes back, and Start pauses. On-screen prompts show the connected controller’s labels.

Change the control style under OPTIONS → PLAYER OPTIONS → CONTROLLER. During multiplayer, use PLAYER CONTROL in the pause menu. The control style determines the gameplay buttons; additional multiplayer pads use the RIGHT STICK layout below.

For mouse sensitivity and inversion, open the Controller page. The title menu calls the settings MOUSE, MOUSE SPEED and SWAP Y; during play they are USE MOUSE, MOUSE SPEED and SWAP Y AXIS.

03 / ProgressSave & resume

  1. Save a single-player game with F7.

    Select one of the four slots and confirm. An occupied slot asks before overwriting.

  2. Resume with F8.

    Select the saved slot, or use START → SINGLE PLAYER → LOAD GAME from the title menu.

Quick save uses slot 1

During play, F9 overwrites slot 1 immediately and F10 loads it. Close menus before using these keys. Keep a separate manual save in another slot if you want a fallback.

Game saves include settings. Multiplayer’s SAVE SETTINGS and LOAD SETTINGS store setup choices, not an in-progress match. The memory-card screens use files on your computer; no PlayStation memory card is needed.

Default save folders. Back up the whole folder before updating.
SystemLocation
Windows%APPDATA%\Q2PSX-PC\saves
Linux / macOS~/.local/share/q2psx-pc/saves, or $XDG_DATA_HOME/q2psx-pc/saves when set.

Use --saves "path/to/saves" to choose a different folder. If a save is missing, check that you launched with the same folder and user account. Keep the disc available when loading a saved game.

To update, extract the new release into a new folder and select your disc again. Default saves remain in your user folder. If you use a custom save path, point the new build at it. Check the release notes for compatibility changes.

04 / Shared screenLocal multiplayer

Two to four players can share one computer in DEATHMATCH, TEAM DEATHMATCH or VERSUS. Network play is not available.

  1. Connect the controllers.

    Keyboard and mouse control player one. Connected gamepads fill players two through four in connection order. To use gamepads for every player, launch with --gamepad-player-one.

  2. Choose START → MULTI PLAYER.

    Select a mode, then set the player count, arena and limits. Use left/right to change values and PROCEED to continue through setup.

  3. Play and finish the match.

    In Deathmatch, press Fire after dying to respawn. Versus players wait for the next round. At the results screen, every player must press Fire before the game continues.

For two players, VIDEO OPTIONS → HORIZONTAL SPLIT chooses the split direction. Three or four players use a four-view layout. If one pad disconnects, the others keep their player assignments.

05 / PreferencesDisplay & sound

The game opens in a resizable window. The default --aspect auto adapts the view to the window’s shape, while menus and films keep their proportions. For a traditional view, use --aspect 4:3. V cycles aspect modes.

Open OPTIONS from the title or single-player pause menu.
SettingEffect
Video Options → CRT EmulationAdds scanlines, a phosphor grille and screen curvature. Off by default; a CPU fallback is available.
Video Options → BloomAdds glow to bright scene surfaces without blurring HUD text. Off by default; requires the OpenGL display backend.
Sound OptionsAdjust music, sound effects and stereo output.
Player Options → CrosshairToggle the aiming crosshair.

RESET TO DEFAULTS resets the current options page; on Video Options it also turns CRT and bloom off. These presentation effects are optional additions to the recreated PlayStation rendering.

The software renderer uses affine textures and 15-bit colour. Enlarging the window does not turn it into a modern perspective-correct renderer. A claim of complete hardware equivalence has not been established.

06 / RecoveryTroubleshooting

The disc is missing or will not open.
Use BROWSE IMAGE and select the CUE. Check that its referenced track files exist with matching names. If using a physical disc, insert it and refresh the selector with F5. On Linux, check your account’s permission to read the optical drive.
The selector says this is not a Quake II PlayStation disc.
Confirm the edition and serial against Supported discs. Do not rename a compressed image to BIN or ISO; use a supported image of your own disc.
Levels work, but music or films are missing.
Use a complete raw CUE/BIN image. A 2048-byte ISO or a drive that only returns cooked sectors lacks the XA data needed for music and films. Also check the Music volume under Sound Options.
Windows reports a missing SDL3.dll.
Extract the complete release again. Keep its SDL3.dll beside q2psx.exe; copying the executable alone is insufficient.
The executable will not start.
Check that the archive matches your system and architecture. On Linux and macOS, launch ./q2psx from a terminal to see the error. If an archive tool dropped the executable permission, run chmod +x q2psx in the extracted folder. A macOS security prompt is separate from a game error; review the download’s origin before approving it in system settings.
The display is slow or a display effect is missing.
Turn off CRT and bloom, then reduce the window size. --crt-cpu can help diagnose an OpenGL display problem, but it may be slower and does not provide bloom.
A controller controls the wrong player.
Quit, connect the pads in the intended order, and relaunch. Single-player takes the first pad; multiplayer reserves player one for keyboard and mouse unless --gamepad-player-one is supplied.
A save fails or appears to be missing.
Check the save folder, write permissions and free space. A launch with --saves uses that path instead of the default. Quick save overwrites slot 1; use other slots for backups.

Report a problem

Include your operating system, the output of q2psx --version, the disc serial, level name, and steps to reproduce the issue in the project issue tracker. For a visual issue, attach an F11 capture.

Normal Windows desktop launches write diagnostics to %APPDATA%\Q2PSX-PC\q2psx.log. On Linux or macOS, keep the terminal output. Review logs for personal paths before sharing; do not attach disc images or extracted game files.

07 / ReferenceLaunch options

Run commands from the extracted folder. Quote paths containing spaces.

Windows PowerShell

.\q2psx.exe --disc "D:\Games\Quake II\game.cue"
.\q2psx.exe --disc E:

Linux / macOS terminal

./q2psx --disc "/path/to/Quake II/game.cue"

For a physical drive on Linux, use --disc /dev/sr0. Physical-drive support is not implemented on macOS; use a disc image.

Common options; --help lists the full diagnostic interface.

The bundled q2psx-inspect and stx2avi are optional inspection and movie-conversion tools. They are not needed to play. Contributor workflows and diagnostic captures are documented in the online developer reference.

08 / ProjectAbout & credits

Q2PSX-PC recreates Hammerhead’s 1999 PlayStation edition as a native application. It remains a work in progress: campaign and local multiplayer systems are implemented, but complete gameplay and hardware parity are not claimed. See the current subsystem audits and the release notes for known limits.
